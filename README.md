A chess engine in at most 4,096 bytes of Python: alpha-beta search with quiescence, a transposition table and piece-square evaluation, playing the house gauntlet through the env. It searches to a fixed node budget, never a clock, so replays match.

## Run it

```sh
MAKEFUN_ENV_URL=http://store:8080 python3 main.py
```
